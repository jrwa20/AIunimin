BOGOTÁ · BICIAYUDA

Primero inicia la aplicación.

BiciAyuda necesita su servidor local. Abrir index.html directamente en Chrome no inicia el análisis, el chat ni la base de datos.

  1. Extrae el ZIP completo a una carpeta.
  2. En Windows, haz doble clic en INICIAR-WINDOWS.bat. Necesitas Python 3.11 o superior; la primera ejecución descarga las dependencias.
  3. En Linux o macOS, abre una terminal en esta carpeta y ejecuta python3 iniciar.py.
  4. Mantén abierta la ventana del servidor. Después abre la dirección siguiente en Chrome.
Abrir BiciAyuda local

Si Chrome dice que no se puede acceder, el servidor no está iniciado. Si la ventana de inicio muestra un error, conserva el mensaje para revisarlo.
